# P3-04 — UI/HUD and onboarding pass

**Files:**
- Create: `src/phaser/ui/hud-panel.js`
- Create: `src/phaser/ui/tower-shelf.js`
- Create: `src/phaser/ui/overlay-ui.js`
- Modify: `src/phaser/playground-scene.js` (integrate HUD/shelf/overlay)
- Modify: `src/phaser.html` (ensure UI overlay container is in place)

**Objective:** Add a complete Phaser-based UI layer that covers tower selection, wave start, pause/resume, speed toggle, economy display, wave countdown, and tower inspection. All UI is Phaser render objects — no DOM.

**Acceptance:**
- Player can select a tower type from the shelf, then click the map to place it.
- Player can click placed towers to inspect them (stats, upgrade cost, sell value).
- Wave start button is visible and functional.
- Pause/resume and speed toggle buttons work.
- Economy (money, lives) is visible in the HUD.
- Wave countdown timer displays before each wave.
- Tower selection is visually distinct (highlighted shelf item + range ring on map).
- Tower inspection panel shows: name, level, damage, range, fire rate, upgrade cost, sell value.
- Tower shelf has all 5 tower types: tranq (200), fence (150), drone (250), heli (300), chrono (400).
- Tower shelf and HUD remain visible at all times and don't obscure the battle area.
- All Phaser objects are destroyed on scene shutdown.

**Design spec:**

### Tower Shelf (bottom, 1280×80px band)
- Background: semi-transparent dark green (0x17231d, alpha 0.85)
- Each tower slot: 100×70 px rounded rect with tower type name and cost
- Selected tower: bright cyan outline (0x6fe3c1, stroke width 3)
- Too expensive: grayed out (alpha 0.4)
- Tower type icons: colored circles matching tower.accent colors
  - tranq: #66bb6a (green)
  - fence: #f2b75b (amber)
  - drone: #42a5f5 (blue)
  - heli: #ef5350 (red)
  - chrono: #ab47bc (purple)

### HUD Panel (top-right, ~260×120px)
- Background: semi-transparent dark green (0x17231d, alpha 0.85)
- Lives: heart icon (♥) + count in red
- Money: $ + count in amber
- Wave: "WAVE X/10" in white
- Speed: "1×" or "2×" button
- Pause: "❚❚" button

### Wave Countdown Overlay
- Appears 3 seconds before wave start
- Large text: "WAVE X INCOMING" with countdown timer
- Fades out at wave start

### Tower Inspection Panel (appears on tower click)
- Slides in from right side
- Shows: tower name, level, damage, range, fire rate, upgrade cost, sell value
- Buttons: "UPGRADE" and "SELL"

### Onboarding (first run only)
- Semi-transparent overlay on first boot
- Brief text: "Select a tower from the shelf below, then click the map to place it. Start the first wave when ready."
- Dismissed on first tower placement or wave start
